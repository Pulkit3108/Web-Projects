# iNotebook

A MERN notes application with registration, sign-in, and note CRUD operations.

## Run Locally

Install dependencies for both the React frontend and Express backend:

```bash
npm ci
cd backend
npm ci
cd ..
npm run both
```

Configure the backend’s MongoDB connection and JWT secret in local environment configuration before starting it. Do not commit those values.

## Commands

- `npm start` — React development server
- `npm run both` — frontend and backend together
- `npm run build` — frontend production build
