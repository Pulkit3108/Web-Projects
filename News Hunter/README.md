# News Hunter

A React news reader that groups current articles by category through News API.

## Run Locally

```bash
npm ci
npm start
```

The app runs at `http://localhost:3000`. Configure any News API key locally; do not commit it.

## Commands

- `npm start` — development server
- `npm run build` — production build
- `npm test` — test runner
